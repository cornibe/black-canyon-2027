# Black Canyon 100K 2027 Family Trip

A static trip-planning website for the February 2027 Black Canyon 100K, including race logistics, family nature outings, lodging, flights, budget, schedules, official links and an interactive reference map.

## GitHub Pages

In the repository, open **Settings → Pages** and select:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

The site will be available at:

`https://cornibe.github.io/black-canyon-2027/`
